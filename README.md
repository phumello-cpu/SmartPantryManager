# Smart Pantry Manager

## Project Overview

Smart Pantry Manager is a Java-based Android application developed for the Mobile App Development 700 assignment at Richfield Graduate Institute of Technology.

The application helps users manage pantry ingredients and identify recipes that can be prepared using available ingredients. It aims to support household food management and reduce food waste.

## Implemented Features

- Add pantry ingredients.
- View the pantry ingredient list.
- Edit ingredient details.
- Delete pantry ingredients.
- View recipe suggestions based on available ingredients.
- Display recipe ingredients and preparation instructions.
- Store pantry and recipe data using SQLite.

## Technologies Used

- Java
- Android Studio
- Android SDK
- SQLite
- XML layouts

## Database

SQLite is used to store pantry ingredients and recipe information locally on the device.

## Installation Instructions

1. Download or clone this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronisation to complete.
4. Run the application on a compatible Android emulator or Android device.
